### CapStoneETKJ
CapStone Project for VLC-SCADF by LHub

### Problem Statement
Use data analytic to analyse how do NOCs perform in Summer and Winter Olumpics and what is(are) the factor(s) that contribute to success of NOCs in those events.

### Research Objective
1. if there is a relationship between athlete age and medal probability, and if there is an optimal winning age by sport?
2. If there is a relationship between athlete profile (ie height/weight) and medal probability, and if there is an optimal winning profile by sport?
3. Does Host nation have an medal advantage? 
4. Is there a co-relation between number of participant and the number of madels
5. How has the number of NOCs entering each sport changed over time and which sport globalised fastest?
